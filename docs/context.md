# Tech Stack

- React
- TypeScript
- TailwindCSS
- MUI (Material-UI)

# Project Description

This application is designed to help users learn Chinese characters and phrases. Users can upload their own text in a specific JSON format, which will be displayed as full Chinese text with the option to see pronunciation and definitions for each character.

## Installation

To get started with this project, follow these steps:

1. Clone the repository:

   ```bash
   git clone <repository-url>
   cd <repository-name>
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm start
   ```

## Technology Stack

- **React**: JavaScript library for building user interfaces.
- **TypeScript**: Superset of JavaScript that adds static types.
- **TailwindCSS**: Utility-first CSS framework.
- **Material-UI (MUI)**: React components for building consistent and beautiful UIs.
